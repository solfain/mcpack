# mcpack

Home of the **Vermeil** resource pack and its port to modern Minecraft.

| file | what it is |
| --- | --- |
| `vermeil_under_25mb.zip` | the original legacy pack (pack format 1, ~1.7-era layout: `textures/blocks`, `mcpatcher/`) |
| `dist/Vermeil-1.21.11.zip` | **the ported pack — this is the one you install** (format 75, tested against 1.21.11 asset paths) |
| `tools/port_pack.py` | the porting tool (path/name migration + metadata, never touches pixel data) |
| `tools/build_port.sh` | one-shot rebuild of the port from the source zip |
| `tools/fetch_vanilla_paths.sh` | pulls the canonical vanilla asset tree used to validate every rename |
| `docs/port-report.md` | full report: what moved, what was kept, what could not be mapped |
| `mod/` | **mcpack-sky** - a Fabric client mod that renders the pack's OptiFine-layout custom skies without OptiFine (work in progress) |
| `dist/mod/mcpack-sky-0.1.0.jar` | build output of that mod, published automatically by GitHub Actions |

## Install

1. Download `dist/Vermeil-1.21.11.zip`.
2. Drop it in `.minecraft/resourcepacks/` (Windows: `%appdata%\.minecraft\resourcepacks`).
3. In game: **Options → Resource Packs** → enable **Vermeil**.

No unzipping needed. Target version: **1.21.11** (also loads on 26.1+ — `max_format` is set to 86).

## What the port changed

* `pack.mcmeta` → `pack_format 75`, `min_format [75,0]`, `max_format [86,0]` (the 1.21.9+ range form), original creator credits kept.
* Every texture moved to the path 1.21.11 actually reads: `textures/blocks` → `textures/block`, `textures/items` → `textures/item`, plus all the 1.13/1.21 renames (`wool_colored_red` → `red_wool`, `log_big_oak` → `dark_oak_log`, `noteblock` → `note_block`, `melon` → `melon_slice`, …).
* Armor sheets (`models/armor/*_layer_1/2`) → `textures/entity/equipment/humanoid/` + `humanoid_leggings/` (the 1.21.2+ equipment layout).
* Mobs that gained variants in 1.21.5 get their art replicated across the new folders (`cow/` → `temperate/cold/warm`, `pig/`, `chicken/`).
* `mcpatcher/` → `optifine/` (OptiFine / Continuity / Fabric mods read these paths):
  `optifine/ctm/glass`, `optifine/colormap` (incl. `sky0.png`), `optifine/lightmap`, `optifine/sky`, `color.properties`.
* The clock and compass strips are sliced into the 64/32 per-frame files modern Minecraft expects (`clock_00.png` … `compass_31.png`).
* `font/default.json` + `font/alt.json` are generated so the pack's 2× HD font actually appears: `ascii.png`, `ascii_sga.png` and all 222 `unicode_page_*.png` sheets are wired in at their correct size. (The `legacy_unicode` provider that used to load these pages was removed in 1.20, so they are registered as `bitmap` providers instead.)
* OS junk (`Thumbs.db`, `.DS_Store`, `- Copy` files) dropped; 24 obsolete/duplicate texture names dropped.

**Pixel data is untouched.** 1050 of the 1146 output files are byte-identical to the source pack; the only regenerated bytes are the 96 sliced clock/compass frames.

## Known gaps

* **GUI / HUD art (`textures/gui/icons.png`, `widgets.png`, `options_background.png`, the creative tabs, etc.) is carried over but inert.** 1.20.2+ loads those as individual sprites under `textures/gui/sprites/…` instead of sheets, so the old sheets are ignored by the game. Porting them means slicing each sheet into ~90 named sprites — a follow-up job, say the word.
* `mcpatcher/anim/` (a MCPatcher animated-inventory hack) is kept in the pack but no longer works — that feature was dropped by OptiFine years ago.
* Skulls, spawn eggs, bed items and double chests: the old single textures have no 1:1 modern file (modern uses variants/split textures), so they are kept as-is at their legacy paths rather than guessed at.
* Font size: the pack's font is 2× resolution and is registered at vanilla text size. For the "big HD text" look, change `"height": 8, "ascent": 7` to `16 / 14` in `assets/minecraft/font/default.json`.

## Rebuild / retarget

```bash
tools/build_port.sh                    # rebuild dist/Vermeil-1.21.11.zip from the source zip
tools/fetch_vanilla_paths.sh 1.21.11   # refresh the vanilla path list (needs gh)
```

To target another version, edit `BLOCK_MAP` / `ITEM_MAP` / `ENTITY_MAP` in `tools/port_pack.py`, pass
`--pack-format <N>` (see the Minecraft Wiki pack-format table) and validate with `--vanilla-paths`
from that version's tree. Anything the tool can't place confidently is reported, never silently dropped.
